# 💪 AI Fitness Intelligence Platform

An end-to-end AI-powered Fitness Analytics Platform built using SQL Server, Python, Machine Learning, Streamlit, and Power BI.

---

## 📌 Project Overview

This project helps users track their fitness journey by analyzing workouts, nutrition, sleep, and body metrics. It also predicts future weight using Machine Learning and provides AI-based recommendations.

---

## 🚀 Features

- 👤 User Management
- 🏋 Workout Tracking
- 🥗 Diet Tracking
- 😴 Sleep Analysis
- 📈 Progress Tracking
- 🤖 Weight Prediction (Machine Learning)
- 💡 AI Health Recommendations
- 📊 Interactive Streamlit Dashboard
- 📈 Power BI Dashboard
- 🗄 SQL Server Database

---

